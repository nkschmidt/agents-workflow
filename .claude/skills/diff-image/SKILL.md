# diff-image — Render незакоммиченных изменений в картинку

## Когда применять

- Пользователь явно попросил визуализировать diff. **Не запускать автоматически.**

## Аргументы

`ARGUMENTS` — путь к директории, где запустить diff (рабочая область или `.`). Без аргумента — текущая директория.

## Процедура

### Шаг 1 — запустить скрипт

Одна команда:

```bash
ROOT=$(git rev-parse --show-toplevel) && bash "$ROOT/.claude/skills/diff-image/diff.sh" "$ROOT" "$ROOT/<TARGET_DIR>"
```

- `<TARGET_DIR>` — из `ARGUMENTS` (например `submodules/backend`). Без аргумента — не передавать второй параметр (скрипт возьмёт project root).

Скрипт автоматически установит `silicon` если его нет (brew на macOS, cargo на Linux). Картинки кладутся в `.tmp/` (gitignore).

### Шаг 2 — обработать результат

Скрипт возвращает JSON на stdout:
- `{"status":"ok","diff":"<path>","untracked":"<path>"}` — картинки сгенерированы. `"none"` = нет таких изменений.
- `{"status":"clean"}` — нет незакоммиченных изменений. Сообщить пользователю.
- `{"status":"error","message":"..."}` — ошибка. Показать сообщение.

### Шаг 3 — отправить картинки

Для каждого пути из JSON (кроме `"none"`):
1. Вызвать `send_image_to_user` с **абсолютным путём**.
2. Fallback — `Read <path>` если `send_image_to_user` недоступен.

## Запрещено

- Запуск без явной команды пользователя.
- Любые правки git-state (`git add`, `git stash`, `git commit`).
